Installation complete — one system confirmation remains

If macOS asks whether TextInputMenuAgent may enable LingoSphere, click Allow. The new installer makes one enable request and no longer forces a programmatic input-source switch.

When prompted by Installer, log out of your Mac account and sign back in. Then choose “LingoSphere - Simplified Chinese” from the Input menu.

On first use, choose one candidate-translation language: English, Japanese, Korean, German, French, Spanish, or Brazilian Portuguese. You can switch it at any time from the LingoSphere menu.

If that language is not installed yet, macOS will show Apple's official language-download panel. Follow the prompt to download it.

The legacy Squirrel input source is disabled before its app is moved out of the Input Methods folder and backed up. Personal dictionaries and settings are preserved. Choose “LingoSphere Settings…” for visual access to common options.
